## Code Blocks & Syntax Highlighting (كتل الأكواد)

Code blocks should have a warm background, beautifully matching the serene overall theme rather than using harsh dark defaults. Note the soft sage greens and warm browns.

```javascript
// Function to generate a serene color palette
function generateSerenePalette() {
  const baseColor = "#F9F5F0"; /* Soft, warm background */
  const accent = "#D4A373"; /* Subdued amber / soft bronze */
  const text = "#3C2E21"; /* Elegant text color */

  console.log("Applying the Serene Digital Garden layout...");

  return {
    background: baseColor,
    primaryText: text,
    interactive: accent,
    isHarmonious: true,
  };
}
```

Inline code like `pip install mkdocs-material` should also blend effortlessly into the text.
